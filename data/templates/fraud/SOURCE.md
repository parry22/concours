# Fraud template data source

`dataset.csv` is built by `scripts/fetch_data.py` from the daily files
`data/2018-07-01.pkl` through `data/2018-07-31.pkl` published at
https://github.com/Fraud-Detection-Handbook/simulated-data-raw (about 297,000 transactions,
fraud rate about 0.85%).

The data was generated by the transaction simulator described in the Fraud Detection Handbook,
Le Borgne, Siblini, Lebichot and Bontempi, Universite Libre de Bruxelles, Machine Learning Group:
https://fraud-detection-handbook.github.io/fraud-detection-handbook/Chapter_3_GettingStarted/SimulatedDataset.html

License notes: the handbook's code is GPL v3 and its prose is CC BY-SA 4.0. Concours copies no
handbook code; it only reads the published data files. The data repository itself carries no
license file. Credit: ULB Machine Learning Group.

Columns: TRANSACTION_ID, TX_DATETIME, CUSTOMER_ID, TERMINAL_ID, TX_AMOUNT, TX_TIME_SECONDS,
TX_TIME_DAYS, TX_FRAUD, TX_FRAUD_SCENARIO. `TX_FRAUD_SCENARIO` is non-zero only for fraud rows,
which is the planted leak the data protection step must catch.
